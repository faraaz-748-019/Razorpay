How ACG Solves It At The Merchant's Edge

Instead of waiting for global standards to unify, ACG acts as an edge translation gateway in front of Razorpay test rails. Any agent connects in its native dialect — ACG bounds, verifies, explains, and settles the order seamlessly.

Key Innovations

Everything Built For Track 01

Every requirement fulfilled with zero compromises: explainable, bounded, and gated.

Universal Protocol Adapter

Simultaneously exposes endpoints tailored for ACP sessions (`/api/protocols/acp`) and AP2 atomic mandates (`/api/protocols/ap2`) routing into the same unified Razorpay order settlement engine.

Cryptographic Mandate Authority

Before any money moves, the agent must present a tamper-proof signed authorization token containing a hard spending cap, category whitelist, and TTL expiry.

SHA-256 Hash-Chained Audit Ledger

Every search, cart add, upsell, and payment gets cryptographically chained (`Hash_n = SHA256(data + Hash_n-1)`). Accompanied by full natural-language justifications for every verdict.

Circuit Breaker & Graceful HITL

Out-of-bounds agent behavior (velocity spikes, cap breaches, unauthorized categories) trips the circuit breaker, cleanly pausing execution for Human-In-The-Loop approval instead of crashing.

Headroom Upsell Growth Engine

Dynamically calculates unspent mandate budget headroom (`Cap - Subtotal`) and presents high-margin complementary add-ons that agents evaluate live, increasing merchant AOV.

Auto-Generated MCP Discovery

Any product added to the store instantly updates the agent-callable MCP discovery manifest at `/.well-known/agent-commerce.json` without any manual code redeployment.
